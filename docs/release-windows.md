# FlowHMR Windows v0.3.6

这一版把自定义骨架的重定向整合到桌面工作区，并简化了导出。导入视频、选择人物、生成 3D 动作后，可以直接把动作应用到自己的角色，再按需要导出。

- **自定义重定向和角色库。** 浮动面板可拖动、缩放，支持 3D 拾骨、骨名搜索、T／A Pose 参考和独立蒙皮开关。引导从身体继续到双手，左右镜像默认开启；也可以用可自定义的 R／G／S 快捷键检查骨骼带动的部位。程序按目标身高、臂长、腿长调整动作。角色会保留自己的匹配与校正；可复用的预设支持缩略图、自定义预设删除和内置预设恢复默认。
- **按当前角色导出 FBX。** Mixamo 和 MetaHuman 不再有独立的模板文件框。普通自定义 FBX 和已识别的 FBX 角色都可选择「当前角色 FBX」，保留模型原骨架、已保存的重定向和校正，蒙皮可选。多人场景一次导出一位，保留该人站位和入场时间。Mixamo 的通用骨架与 VRM 的 GLB／VRMA 导出保留。
- **PMX 重心与 IK／FK。** 重定向面板可切换 IK／FK。PMX 自动重心先尝试「センター」，不可用时尝试「全ての親」；已保存的手动绑定继续优先，独立分支上的兼容脚与脚尖 IK 也能随角色导出。
- **通用 VMD 沿用角色校正。** 应用角色后，导出通用骨架会保留关节旋转与位移、根骨调整和脚部 IK／FK，使用标准 MMD 骨名。未应用角色时仍可照常导出。要保留角色的精确比例和鞋底贴合，请选按当前 PMX 角色导出。
- **播放与角色预览。** 慢放时在原轨道上插值，时间轴显示帧率可单独切换并记住，不改变素材同步或导出时长。改进角色缩略图和 FBX／VRM 切换，修复部分 VRM 克隆时丢失弹簧骨碰撞体、Mixamo 角色脚部因绑定姿势而额外上翘的问题。
- **AMD Radeon RX 6000（实验中）。** Windows 11 的运行环境按架构匹配 ROCm 7.14.0。四组安装包已核对、解包并通过 CPU 侧加载；没有 RX 6000 实卡的完整动捕结果，4 GB 型号也没有运行结论。
- **启动与设备选择。** 便携版未安装推理环境时仍可打开工作区；开始生成时才初始化推理。桌面和命令行区分 CPU、CUDA、ROCm 和已接入的 Intel XPU，未加入 Apple MPS 支持。
- **MCP 兼容性。** 原有 19 个工具与后台导出参数保持兼容。MCP 现在能为已绑定控制骨的自定义 FBX／VRM 切换 IK，状态接口可读取实际设备后端。按当前角色及沿用角色校正的通用 VMD 属于桌面导出流程；MCP 后台导出仍使用原始动作，无须打开预览窗口。

### 验证范围

| 项目 | 核验结果 |
| --- | --- |
| 自定义重定向 | 用实际 PMX、VRM、Mixamo、MetaHuman，以及名称不受内置方案识别的骨架，核对角色导入、选骨、肢体比例、镜像、双手引导和预设重开。 |
| 当前角色导出 | 用 478 帧动作导出自定义 `rig_unknown_wrists`，在 Blender 3.6 和 4.5 回读：32 根原骨骼与层级、20° 头部校正、12 厘米根骨调整、可选蒙皮均通过。Mixamo、MetaHuman 的按角色 FBX 和自定义 VRM 的 GLB 也通过验证。 |
| 通用 VMD | 同一段 478 帧动作从界面导出并回读：五个抽查帧都保留 20° 头部校正，验证了关节与根骨的旋转、位移，以及左右脚踝、脚尖 4 个 IK 控制器的两种常见命名。FK 导出会关闭这些控制器。 |
| MCP | 用便携 CPU 环境连接真实 MCP 客户端，发现 19 个工具，24 项 MCP 回归通过；验证原始动作的无窗口导出，并连接界面检查跳帧、暂停和角色骨骼编辑。 |
| 播放和 CPU | 实测慢放、进度拖动和循环，固定机位与运动相机均跑通 CPU 四帧动捕。 |
| RX 6000 | 实验支持；核对 gfx1030、gfx1031、gfx1032、gfx1034 的 Windows 安装包。真实 GPU 推理尚待验证。 |

旧版可以从软件顶栏 **检查更新** 进入更新，也可手动导入下载的官方 ZIP；网络不可用时仍可继续使用现有版本。更新会保留模型、角色库、运行环境、设置和任务历史。
