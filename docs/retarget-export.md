# 动作导出与角色预览

在预览结果右上角点 **导出动作**，或从 **文件 → 导出动作** 选择格式。NPZ 可单独导出。桌面版可在系统保存窗口选择文件名和目录，下次导出会从上一次成功保存的目录打开。

| 格式 | 适合的用途 | 选项 |
| --- | --- | --- |
| FlowHMR FBX | Blender 等软件里的通用重定向源 | 可选蒙皮，可在第 −1 帧插入 T Pose 或 A Pose；可把多人放在同一个 FBX |
| Mixamo FBX | 通用 Mixamo 骨架，或按当前 Mixamo 角色导出动作 | 两种模式都可带蒙皮。通用骨架支持参考姿势和多人；当前角色模式会写入已有的重定向和校正 |
| MetaHuman FBX | 按当前 MetaHuman 角色导出身体和手指动作 | 先在「角色」中应用 MetaHuman 身体 FBX，每次导出一人的骨骼动画 |
| 当前角色 FBX | 将普通自定义 FBX 或已识别的 FBX 角色带回动画软件 | 保留原骨架及保存的重定向和校正；可选蒙皮。多人场景一次选一人，保留站位和入场时间 |
| Maya AdvancedSkeleton FBX | Maya 的 AdvancedSkeleton 动作库 | 导出一人的动画骨架，第 −1 帧为 T Pose |
| MMD VMD | 给 MMD 人形角色播放动作 | 选用当前预览 PMX 或通用骨架；已应用角色的关节校正、根骨调整和脚部 IK／FK 可随通用骨架导出。30 FPS，多人分别写入 VMD 再打成 ZIP |
| VRM Animation (.vrma) | 给支持 VRM Animation 的应用提供通用人形动作 | 保留源帧率、身体、手指和根骨位移。多人时保留各自的时间和站位，每人一个 VRMA，打包成 ZIP |
| VRM 角色 GLB | 将自定义重定向的 VRM 角色和动画导入支持 glTF 的软件 | 保留当前匹配、校正和蒙皮；FBX 角色用「当前角色 FBX」 |

要导出普通自定义 FBX，先在「角色」中给对应人物应用带蒙皮的 FBX，在「重定向」完成匹配后点「保存并应用」。再打开 **导出动作 → 当前角色 FBX**，选择是否包含蒙皮。导出沿用该角色的原骨架及已保存的动作校正；多人场景从列表选一人，保留其站位和入场时间。若「导出」不可用，先确认选中人物已应用 FBX 角色。**FlowHMR FBX** 仍导出源 SMPL-H 动作。

**Mixamo FBX** 可直接导出通用骨架。也可以在「角色」中应用带蒙皮的 Mixamo FBX，选中该人物后导出框会默认使用当前角色。可在导出框切回通用骨架。按角色导出保留原骨架和当前的重定向校正。[Adobe Mixamo 说明](https://helpx.adobe.com/creative-cloud/help/mixamo-rigging-animation.html)

在 iClone 中，可使用已验证能正常导入的 Mixamo 角色，在 FlowHMR 的「角色」中应用后导出。选择 **File → Import → Import External Motion**，为导出的文件选同一个 **Motion Profile**。如需指定 **Motion T-pose**，使用同一角色的 T Pose 文件。[iClone 外部动作导入说明](https://manual.reallusion.com/iClone-8/Content/ENU/8.4/50-Animation/Import-External-Motions/Import-External-Motions.htm)

在 Maya 里使用 AdvancedSkeleton 的 **MoCapLibrary → Motion Capture (Custom)** 时，选择 **Maya AdvancedSkeleton FBX**。在动作库中浏览到保存目录，选中 FBX 后点 **Apply**。动作库会用第 −1 帧对齐源骨架。使用 **MoCapMatcher** 的用户也可导入通用 **Mixamo FBX**，选择 Mixamo 模板后扫描骨架。 [AdvancedSkeleton 官方页面](https://www.animationstudios.com.au/)

在 Maya 中拖入 [ADV 帧率助手](../tools/maya/flowhmr_adv_timing.py) 打开面板。也可在 Script Editor 的 Python 页打开脚本并执行。

1. 点 **准备 30 FPS**，再从 Custom 动作库选中 FlowHMR 的 FBX，点 **Apply**。
2. 点助手里的 **FBX 已应用**，然后在 ADV 中执行 **Bake Body**。在这个阶段保持 30 FPS，检查动作时使用实时 1× 播放。
3. 点 **烘焙完成，恢复原帧率**。Maya 按秒保留烘焙关键帧和播放范围。回到 24 FPS 工程时，部分关键帧会落在小数帧上。

助手的 **提前恢复** 会结束临时帧率设置。Bake Body 按当前场景帧率取样，使用 30 FPS 可以保留 FlowHMR 的每个原始采样点。 [Maya 播放设置](https://help.autodesk.com/cloudhelp/2023/ENU/Maya-Customizing/files/GUID-51A80586-9EEA-43A4-AA1F-BF1370C24A64.htm) · [Maya 时间单位](https://help.autodesk.com/cloudhelp/2026/ENU/Maya-Tech-Docs/CommandsPython/currentUnit.html)

已回读核对 FBX 的动作帧和时长，并模拟验证了助手的帧率切换。实际 Maya ADV 应用和烘焙前后的动作对照仍待实机验证。

MetaHuman 工作流：在 Unreal Engine 的内容浏览器中找到目标角色的 **Body** Skeletal Mesh，用 **Asset Actions → Export…** 导出身体 FBX。在 FlowHMR 的「角色」中应用一次，需要时调整并保存重定向。导出 **MetaHuman FBX** 后，在 Unreal 导入时选择**同一个身体 Skeleton**。文件保留角色的骨骼层级及校正后的身体和手指动作。参见 [Epic 的 FBX 动画导入说明](https://dev.epicgames.com/documentation/unreal-engine/importing-animations-using-fbx-in-unreal-engine)。

T Pose 和 A Pose 写入 FBX 的第 −1 帧，作为动画关键帧。T Pose 朝正前方。Blender 默认以 +1 帧导入，请在骨架的「姿态位置」查看第 0 帧。若导入时把动画偏移设为 0，则查看第 −1 帧。「静置位置」显示绑定姿势。

v0.3.2 的 VMD 按 30 FPS 逐帧写入动作，并使用 MMD 兼容的线性插值。旧任务可以直接重新导出 VMD。已在 MikuMikuDance 9.26 CHS 的 30 和 60 FPS 播放设置下对照测试。

导出前先「保存并应用」重定向设置。选 **通用骨架** 时，关节校正按人体关节转换到标准 MMD 骨名，脚部保留 IK／FK；只烘焙选中的人物，每个人都使用自己的设置。选 **当前 PMX** 时使用模型原有骨名、肢体比例、鞋底和控制链。没有应用角色时，仍可以从源动作直接导出通用 VMD。

打开一条任务后，在 3D 视图点 **角色 → 选择模型文件…**，选择角色主体的 **PMX、VRM** 或带蒙皮的 **FBX**，再点「应用角色」。已有角色设置、兼容预设或内置方案会直接应用。找不到方案时，程序会询问是否手动重定向；取消会保留当前角色。PMX 和 FBX 的外置贴图放在模型旁边或其子文件夹。桌面版应用后会将模型和引用到的贴图转存到 `models/characters`，以后可以从缩略图选回。

VRM 预览支持 0.x 和 1.0 人形模型。程序从文件内加载贴图、MToon 材质和人形骨骼映射，随动作更新 VRM 1.0 的节点旋转、扭转与瞄准约束。

导出 VRMA 后，在支持 VRM Animation 的应用中先打开 VRM 角色，再导入动作。VRMA 写入生成结果的人形骨骼动作和默认头颈修正。角色网格、材质、面部表情和每个预览角色的手动骨骼调节由使用端单独处理。[VRM Animation 格式](https://vrm.dev/en/vrma/)

多人任务中，先在「角色」面板选人物，再为这个人应用模型。每人可以使用不同角色，动作时间和相对站位与原任务一致。新任务沿用同类任务最近的角色选择，多人按人物编号沿用。备份或迁移时可复制整个 `models/characters` 文件夹。

清理角色时，在「角色库」选中角色并点「删除」。确认后会清理转存的模型和贴图，使用该角色的人物会恢复 SMPL-H。原文件仍留在导入前的位置。

Mixamo 使用带蒙皮的角色 FBX。MetaHuman 在 Unreal Engine 中右键 Body 或合并后的 Full Body Skeletal Mesh，选 **Asset Actions → Export… → FBX**；预览身体和手部动作需要蒙皮网格。单独的骨架、动画 FBX、DNA 或 UE 项目文件不能用来显示角色。预览使用模型里可读取的贴图和通用灯光，不重现 Unreal 的材质节点或面部表情。

应用角色后，可以从视图顶部的 **重定向** 查看或调整匹配和校正。多人时先选人物。点选左侧的 SMPL-H 关节，再在右侧 3D 图中点选目标骨骼，或按名字搜索。左键拖动平移、右键旋转、滚轮缩放。在重定向面板内，按 R、G、S 再移动鼠标，可以临时旋转、平移或缩放选中的目标骨骼，检查它带动哪里，结束后会复位。输入名称或数值时快捷键让给输入框。要保留的调整填在「校正值」，再点「保存并应用」。旋转范围为 −180° 到 180°；重心（根骨）也可按米平移，Y 为高度。

身体引导先从躯干到头，再从肩到手腕、从大腿到脚尖，最后处理重心。接下来依次提示匹配左手和右手，已经绑定的指骨会跳过。可以跳过单根指骨，也可跳过一只手的剩余手指，不会清掉已经确认的绑定。打开面板时，「校正值」默认展开，「自动镜像」默认开启。确认绑定时，只给空白且能可靠识别的对侧补上匹配；已有匹配和主动取消的匹配会保留。调整校正值时，已绑定的对侧会实时镜像。需要单独调整一侧时，先关闭「自动镜像」。

手部没有识别出来时，切到「左手」或「右手」，先绑定手腕。程序会把目标图缩放到对应的手，然后可以逐节拾取手指。PMX 可搜索日文骨名，也可搜索文件提供的英文名。支持常见日文和英文别名；同一骨链有多个合理候选时请手动确认。模型本身缺少的指骨可以跳过。

「角色库」和「重定向预设」默认展开。重定向预设位于左侧的人形骨架下方，右侧下方有操作步骤和当前的快捷键。重定向预设中有 PMX、VRM、Mixamo 和 MetaHuman 的内置卡片；使用兼容的角色可载入、校正并保存到内置预设。「恢复默认」将该预设还原并载入当前草稿，对已保存的角色设置没有影响。自定义预设可单独删除，角色仍保留自己已保存的方案。

勾选「同时保存为可复用预设」可另存当前映射；载入自定义预设后保留原名会更新该预设，改名则另存一份。程序用骨名和父子关系识别类似骨架，再按目标身高和四肢长度重新计算。存在多个兼容预设时，会让你选择。

在重定向右栏顶部的「骨骼模式」可切换 FK / IK，保存后按人物记忆。只有识别或绑定了可用控制器时才能开启 IK。按当前 PMX 导出 VMD 时，兼容的脚和脚尖 IK 在 IK 模式下保持启用，可以继续编辑控制器，马尾等附属姿态会烘焙。FK 模式导出的 VMD 关闭模型 IK。

PMX 的「自动重心」优先选择可用的「センター」，其次是「全ての親」。两者都不可用时，尝试从骨架层级找能带动全身的根骨。可以手动指定重心，已保存的手动绑定会保留。即使脚部 IK 挂在另一条分支，导出也会按同一场景位置记录独立的脚 IK。只带动某个部位的骨骼不能作为整体重心。

面板可拖动标题栏移动，也可用右下角改变大小。

导出按当前角色的 VMD 时，把文件导入同一个 PMX。程序沿目标骨架的父子关系重定向腰背和肩膀，并按角色的手臂、腿长重算手腕和脚踝的位置。通用骨架使用标准 MMD 骨名；如果接收模型的比例或鞋底高度不同，贴地效果可能会有变化。VMD 只含动作，不含网格、贴图或参考姿势。部分旧版 MMD Tools 需先在模型上开启 **Property Drivers（属性驱动）**，导入的 IK 和显示关键帧才会生效。

PMX 预览面向常见人形骨架，例如原神及 Tda 式模型；表情与衣物物理不由动捕驱动，特殊蒙皮在预览中可能近似。改过骨名或使用特殊控制器的模型，建议先用短片段检查预览和 VMD 回读效果。
